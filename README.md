## 💡 Problem-Solving Approach

### **Step 1: Understand**
- Read problem carefully
- Identify constraints and edge cases
- Clarify what's being asked

### **Step 2: Plan**
- Think of simple examples
- Identify patterns
- Plan approach before coding

### **Step 3: Implement**
- Start with clear, working code
- Don't optimize prematurely
- Use readable variable names

### **Step 4: Test**
- Test with provided examples
- Test edge cases
- Test boundary conditions

### **Step 5: Optimize**
- Reduce time complexity
- Reduce space complexity
- Refactor for clarity

### **Step 6: Review**
- Check for bugs
- Verify complexity analysis
- Compare with alternatives

## 🔑 Key Techniques & Patterns

| Technique | Use Cases | Time | Space |
|-----------|-----------|------|-------|
| Two Pointers | Sorted array/list, palindrome | O(n) | O(1) |
| Sliding Window | Substring/subarray problems | O(n) | O(1) |
| Binary Search | Sorted data, search optimization | O(log n) | O(1) |
| Hash Map | Frequency, grouping, lookup | O(n) avg | O(n) |
| DFS/BFS | Tree/graph traversal | O(V+E) | O(V) |
| DP | Optimization, counting | Varies | Varies |
| Greedy | Activity selection, optimization | Varies | Varies |
| Backtracking | Permutations, combinations | Exponential | Varies |
| Union-Find | Connected components | O(α(n)) | O(n) |
| Heap | K-th element, priority | O(log n) | O(n) |

## 📊 Complexity Reference

### **Common Time Complexities**
```
O(1)     - Constant (best)
O(log n) - Binary search, balanced trees
O(n)     - Linear search, array iteration
O(n log n) - Efficient sorting
O(n²)    - Nested loops, bubble sort
O(n³)    - Triple nested loops
O(2ⁿ)    - Exponential, subset generation
O(n!)    - Permutations
```

### **Space Complexities**
```
O(1)     - Constant space (best)
O(log n) - Recursion stack (balanced)
O(n)     - Linear space (arrays, lists)
O(n²)    - Matrix, 2D arrays
O(2ⁿ)    - Subset generation
```
