## 💡 Problem Templates

### **Two Sum Pattern**
```
Problem: Find two numbers that sum to target
Approach: Hash Map
Files: LeetCode1_TwoSum and variants
```

### **Sliding Window Pattern**
```
Problem: Find substring/subarray with constraint
Approach: Expand/contract window with hash map
Files: LeetCode3, LeetCode76, LeetCode567
```

### **Backtracking Pattern**
```
Problem: Generate all permutations/combinations
Approach: Recursive with pruning
Files: LeetCode46, LeetCode78, LeetCode39
```

### **DP Pattern**
```
Problem: Optimize with memoization
Approach: Define state and transitions
Files: LeetCode70, LeetCode322, LeetCode72
```

### **Tree Traversal Pattern**
```
Problem: Traverse tree structure
Approach: DFS (recursive) or BFS (iterative)
Files: LeetCode94, LeetCode102, LeetCode105
```

## ❓ Common Interview Questions

### **"Walk me through your approach"**
✓ DO: Explain step-by-step
✓ DO: Mention time/space complexity
✗ DON'T: Start coding immediately

### **"Can you optimize this?"**
✓ DO: Discuss trade-offs
✓ DO: Show better time or space complexity
✗ DON'T: Optimize prematurely

### **"What are edge cases?"**
✓ DO: Empty input, single element, duplicates
✓ DO: Negative numbers, overflow cases
✗ DON'T: Ignore edge cases

### **"Explain the complexity"**
✓ DO: Clear Big-O notation
✓ DO: Explain each operation
✗ DON'T: Guess complexity
